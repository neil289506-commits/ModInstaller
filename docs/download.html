自行建置

Windows / MSVC 2022 / Qt 6.4+(CI 使用 Qt 6.8)、CMake 3.21+,並需 OpenSSL(vcpkg install openssl:x64-windows-static-md)。Qt 元件:Widgets、Network、Svg、Linguist Tools。

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=<Qt6 路徑>
cmake --build build
windeployqt --release build\ModInstaller.exe
發佈版內建的 CurseForge API Key 可從執行檔取出,請視為半公開金鑰;使用者自填的 Key 優先。

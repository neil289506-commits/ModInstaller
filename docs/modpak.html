Format

.modpak 格式

一個 zip,內含兩個 JSON,只有數 KB。

檔案結構

.modpak 是 zip,內含兩個 JSON:

version.info名稱、Minecraft 版本、載入器與版本、每個模組的託管平台
mod.info每個模組的下載地址、版本號、版本 ID、檔名、sha256

zip 輸出格式:所有模組放在 mods/ 資料夾內。

核心功能

一眼看懂 ModInstaller 能做什麼。

🚫

不用啟動器

只想整理模組清單,不需要建立遊戲實例。

🧬

自動補齊依賴

搜索邏輯移植自 PrismLauncher,Fabric API ↔ Quilted Fabric API 也會自動轉換。

🪶

.modpak 輕量分享

只存模組清單與 sha256,僅數 KB;收到的人再還原成 zip。

🛒

雙平台來源

Modrinth 與 CurseForge 一起搜尋。

🔗

點對點傳輸

12 碼代碼,WebRTC 直連,對方接受後才開始。

🌐

繁體中文 / English

設定中可切換語言。
